# PageSentinel v0.2.0 preview candidate

Local-first website monitoring with clear health and readable changes. PageSentinel is a working title and is not affiliated with the commercial service using that name.

- Public HTML and unique-element monitoring with optional per-origin website access.
- Persisted Chrome alarm scheduling, retries, backoff, pause/resume and visible failures.
- Local text history, exact before/after diffs and policy-paragraph keyword highlights.
- Conservative price rules and phrase/availability alerts.
- Material Design 3 themes: System, Light, Dark and true-black AMOLED, plus six accents.
- Local JSON export and validated paused configuration import.
- Company Privacy Watch, reviewed multilingual policy-link discovery, regional labels and a unified evidence timeline.
- Side-by-side policy comparisons and deterministic categories limited to changed sentences; no privacy scores or external AI.
- Optional authenticated passphrase backup files, fresh paused company imports, website-grant controls and notification snoozing.
- Guided selector repair, atomic bulk management, stable-link new-item detection and conservative complete-message availability rules.
- Skippable onboarding, Overview and contextual advanced controls, with preserved themes and accent preferences.

Extract `pagesentinel-0.2.0.zip`, open `chrome://extensions`, enable Developer mode, choose Load unpacked, and select the extracted folder. Chrome 120+ required; the declared minimum has not been separately tested. Back up before updating the same extension ID/profile to preserve data. Existing v1/v2 storage upgrades transactionally. No Chrome Web Store listing is published. These are candidate notes; the existing v0.1.0 release remains unchanged until an explicitly authorized GitHub publication.

Checks run while Chrome is active and may be delayed. Static public HTML only; no signed-in sessions, dynamic rendering, screenshots or automatic selector substitution. Normal profile history remains plaintext; optional backup files can be encrypted. Websites receive ordinary requests from your network address; no developer backend or telemetry is used. Redirects remain blocked before destination contact. Public-looking DNS names can resolve privately; this is not a complete DNS-rebinding defense. Imports establish fresh live baselines and leave exported history archival in the backup.

Native permission prompts, OS notification presentation, long-running daily use and final naming review remain supervised checks. This is a preview release, not a claim of universal website support.
