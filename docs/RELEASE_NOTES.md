# PageSentinel v0.1.0 preview

Local-first website monitoring with clear health and readable changes. PageSentinel is a working title and is not affiliated with the commercial service using that name.

- Public HTML and unique-element monitoring with optional per-origin website access.
- Persisted Chrome alarm scheduling, retries, backoff, pause/resume and visible failures.
- Local text history, exact before/after diffs and policy-paragraph keyword highlights.
- Conservative price rules and phrase/availability alerts.
- Material Design 3 themes: System, Light, Dark and true-black AMOLED, plus six accents.
- Local JSON export and validated paused configuration import.

Extract `pagesentinel-0.1.0.zip`, open `chrome://extensions`, enable Developer mode, choose Load unpacked, and select the extracted folder. Chrome 120+ required. No Chrome Web Store listing is published.

Checks run while Chrome is active and may be delayed. Static public HTML only; no signed-in sessions, dynamic rendering, screenshots or company-wide Privacy Watch groups. History is plain text on your device. Websites receive ordinary requests from your network address; no developer backend or telemetry is used.

Native permission prompts, OS notification presentation, long-running daily use and final naming review remain supervised checks. This is a preview release, not a claim of universal website support.
