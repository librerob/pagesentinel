# Future Chrome Web Store draft — do not submit under the working name

Historical v0.1.0 draft. For v0.2.0 claims, privacy disclosures, genuine screenshots and unresolved checks, use [release preparation](RELEASE_PREPARATION.md). No store submission has been made. Do not publish before the owner approves final naming and store submission.

Short description: Local website monitoring with readable changes and clear monitor health. No account required.

Description:

Watch public webpages or select a specific element. PageSentinel checks the approved page while Chrome is active, preserves successful versions locally, and shows exactly what changed. A visible health indicator reports failed, overdue, paused and permission-blocked monitors.

Use policy monitors to compare privacy policies, terms or security notices. Keyword rules point to potentially relevant changed paragraphs, with the actual source wording. These highlights are not a legal assessment.

Price rules handle selected prices conservatively. Phrase alerts can track availability notices. Light, Dark, AMOLED and System themes keep the interface comfortable. Export local backups whenever you need them.

No accounts, subscriptions, advertisements or telemetry. Host access is optional and requested only for websites you choose. Checks omit sign-in credentials. Monitored sites see ordinary requests from your network address. History is local plain text; no monitoring data is sent to a developer backend.

Limitations: public HTML only. JavaScript-only pages and signed-in sessions are unsupported. Chrome may delay checks while asleep. No monitoring is guaranteed while Chrome is closed.

Before submission: choose and review the final name, supervise permission/notification checks, host the privacy policy publicly, and use actual fixture screenshots from the final verified build. No store publication is authorized by this draft.
